Privacy

ShoeTracker has no server! All data remains local in your browser and is never transmitted anywhere.

Which data is stored?

ShoeTracker does not process any personal data. All input is stored in your browser’s localStorage under the following keys:

  • shoe_tracker_lang – the language setting
  • shoe_tracker_unit – the chosen unit of measurement
  • shoe_tracker_currency – the set currency for price display
  • shoe_tracker_theme – the selected design light or dark
  • shoe_tracker_data – your shoes and runs
  • shoe_tracker_onboarded – whether the introduction has already been shown

Your data only leaves your device if you export a backup yourself and pass the file on.

What all does not happen?

No cookies are set, no trackers are used, and no fonts, scripts or images are loaded from external servers. The page uses only your device’s system font. There are no analytics tools, no ad networks, no user account, and no login.

This is implemented technically via a strict Content Security Policy default-src 'none': the browser rejects any connection to an external source, even if one were present in the code.

How can I delete my data?

In the app, under Statistics → Data & backup, “Delete all data from this device” permanently removes all stored entries. After that, the app functions as it did on first launch and starts with the onboarding.

You can achieve the same by clearing the site data for this page in your browser settings. Already exported backup files remain unaffected.

What the app cannot prevent

For technical reasons, the host of this page – as with any website visit – sees your IP address and browser type. The page is served via GitHub Pages; the app itself has no influence on that. After the first visit, ShoeTracker can be installed and used offline, so further accesses can take place without a connection to the host.

Source Code

ShoeTracker is open source. The complete code is freely available in the repository on GitHub – without build steps or dependencies, exactly as it is served.
