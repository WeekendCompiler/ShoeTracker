Privacy

In short: ShoeTracker has no server. Everything you enter stays in your browser and is never sent anywhere.

What data is stored

ShoeTracker does not process any personal data on a server – there is none. Everything you enter is kept in your browser’s localStorage under six keys:

  • shoe_tracker_data – your shoes and runs
  • shoe_tracker_theme – the light or dark theme you chose
  • shoe_tracker_onboarded – whether the introduction has already been shown
  • shoe_tracker_lang – the language you chose (German or English)
  • shoe_tracker_unit – the distance unit you chose (kilometres or miles)
  • shoe_tracker_currency – the currency you chose for displaying prices

This data only leaves your device if you export a backup yourself and pass the file on.

What does not happen

No cookies are set, no trackers are loaded, and no fonts, scripts or images are fetched from third-party servers. The page uses only your device’s system font. There are no analytics tools, no ad networks, no user account and no sign-in.

This is enforced technically by a strict Content Security Policy (default-src 'none'): the browser refuses every connection to a third-party source, even if the code contained one.

Deleting your data

In the app, under Statistics → Data & backup, “Delete all data from this device” irrevocably removes everything stored – all of the keys listed above. Afterwards the app looks as it did on first launch. Useful, for example, before you hand the device on.

You get the same result by clearing the site data for this page in your browser settings. Backup files you have already exported are not affected.

What the app cannot prevent

For technical reasons the host of this page – as with any website visit – sees your IP address and browser type. The page is served via GitHub Pages; the app itself has no influence on that. After the first visit ShoeTracker can be installed and used offline, so later launches need no connection to the host.

Source code

ShoeTracker is open source. If you want to verify that nothing is transmitted, the complete code is in the repository on GitHub – no build step and no dependencies, exactly as it is served.
