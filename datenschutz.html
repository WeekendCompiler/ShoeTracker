Zur App

Datenschutz

Kurzfassung: ShoeTracker hat keinen Server. Alles, was du einträgst, bleibt in deinem Browser und wird nirgendwohin übertragen.

Welche Daten gespeichert werden

ShoeTracker verarbeitet keine personenbezogenen Daten auf einem Server – es gibt keinen. Alles, was du einträgst, liegt im localStorage deines Browsers unter sechs Schlüsseln:

  • shoe_tracker_data – deine Schuhe und Läufe
  • shoe_tracker_theme – das gewählte helle oder dunkle Design
  • shoe_tracker_onboarded – ob die Einführung bereits gezeigt wurde
  • shoe_tracker_lang – die gewählte Sprache (Deutsch oder Englisch)
  • shoe_tracker_unit – die gewählte Distanzeinheit (Kilometer oder Meilen)
  • shoe_tracker_currency – die gewählte Währung für die Preisanzeige

Diese Daten verlassen dein Gerät nur dann, wenn du selbst ein Backup exportierst und die Datei weitergibst.

Was nicht passiert

Es werden keine Cookies gesetzt, keine Tracker geladen und keine Schriften, Skripte oder Bilder von fremden Servern nachgeladen. Die Seite nutzt ausschließlich die Systemschrift deines Geräts. Es gibt keine Analyse-Werkzeuge, keine Werbenetzwerke, kein Nutzerkonto und keine Anmeldung.

Technisch durchgesetzt wird das über eine strikte Content-Security-Policy (default-src 'none'): Der Browser verweigert jede Verbindung zu einer fremden Quelle, auch wenn eine im Code stünde.

Daten löschen

In der App unter Statistik → Daten & Backup entfernt „Alle Daten von diesem Gerät löschen“ sämtliche gespeicherten Einträge unwiderruflich – alle oben genannten Schlüssel. Danach steht die App wie beim ersten Start da. Sinnvoll etwa, bevor du das Gerät weitergibst.

Dasselbe erreichst du, indem du in den Browsereinstellungen die Website-Daten für diese Seite löschst. Bereits exportierte Backup-Dateien bleiben davon unberührt.

Was die App nicht verhindern kann

Technisch bedingt sieht der Hoster dieser Seite – wie bei jedem Aufruf einer Website – deine IP-Adresse und deinen Browsertyp. Die Seite wird über GitHub Pages ausgeliefert, darauf hat die App selbst keinen Einfluss. Nach dem ersten Aufruf lässt sich ShoeTracker installieren und offline nutzen, sodass weitere Aufrufe ohne Verbindung zum Hoster auskommen.

Quellcode

ShoeTracker ist quelloffen. Wer nachprüfen möchte, dass hier nichts übertragen wird, findet den vollständigen Code im Repository auf GitHub – ohne Build-Schritt und ohne Abhängigkeiten, genau so, wie er ausgeliefert wird.
